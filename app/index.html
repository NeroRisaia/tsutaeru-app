大切なお知らせ

このアプリの「看護師さんを呼んで」ボタンは、言葉を声と文字で伝えるためのものです。ナースコールの代わりにはなりません。病院・施設のナースコールは必ず別に手の届く場所に置いてください。音が出ても、周りに人がいなければ届きません。

このアプリは、本人が自分で選んだ言葉だけを読み上げます。言いたいことを推測して代わりに話す機能はありません。

読み上げ（音声）について

音声を確認しています…

日本語の音声が入っていないスマートフォンでは、声が出ないことがあります（文字の表示は出ます）。その場合は端末の設定で日本語の音声をダウンロードしてください。

Android の例：設定 → システム → 言語と入力 → テキスト読み上げの出力 →「Google 音声サービス」の歯車 → 音声データをインストール → 日本語。
iPhone の例：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 → 声を選んでダウンロード。

言葉（フレーズ）の編集

ボタンの並び順はここで決めた順のまま固定されます。自動で並び替わるのは「よく使う」だけです。「場所につなぐ」に印をつけた言葉は、押したあとに「体の場所」へ誘導し、「足が痛い」のようにつないで読みます。

カテゴリ

    カテゴリの追加

    使用回数

    「よく使う」は、押された回数の多い言葉（最大6つ）を自動で表示します。

    初期状態に戻す

    言葉とカテゴリを最初の状態に戻します（追加した言葉は消えます）。

    このアプリについて

    つたえる v。データはこの端末の中だけに保存され、インターネットには送信しません。一度開いたあとは、ネットがなくても動きます。
